# 大模型横评报告

把开放网络里的榜单、作者实测和具体用户经验整理为有出处的模型横评。输出用户要求的能力排行、按场景给出的首选和次选、成本对照和可离线打开的单文件 HTML。

1. **锁定本次口径。** 记录日期、厂商/型号、地区与可用入口、预算、用途和优先级。未给维度时，默认科学推理、编程、事实可靠性、智能体办公、文学与对话五维等权，各 100 分。成本单独排序。未给用途时，考察办公与课程文件、开发网页或软件、日常联网问答、辅助学习与题目答疑。前两类评估 Agent 组合，后两类评估普通 App 或网页。设备、账号和订阅状态有不确定性时，使用条件式建议。
2. **先查版本，再查能力。** 每家旗舰用官方发布、定价或产品文档核对，分清预览、灰度、正式、停用、同名别名和各入口实际可选型号。对照可使用同代轻量版或旧型号，但保持独立版本与证据标签。使用 [证据与评分](references/evidence.md) 拓展中英文来源、提取实测并处理分歧。
3. **按证据给分并给建议。** 默认按榜单约 25%、独立实测约 60%、用户经验约 15% 取舍，并兼顾中文约 60%、海外约 40%。用户给的权重优先。解释影响名次和选型的证据、有效反例和适用条件。只有间接或单一证据时标暂定，完全缺证据时记缺测。场景推荐要写实际可用的模型、工具与套餐组合，以及何时由次选换成首选。
4. **组装并验收。** 按 [报告数据与交付](references/report-format.md) 写 UTF‑8 JSON，把可核查来源连到版本、评分、成本、场景和证据卡。可从任意目录运行 `python "<技能目录>/scripts/render_report.py" "<输入文件>" "<输出文件.html>"`。报告把能力排行放在总榜之前，总榜维数由用户所选维度决定。核对每项得分、中文列名次、总分、证据缺口、引用和手机表格。只交付用户所需的文件，在最终说明中交代关键假设或未验证项。

本技能要求可联网检索的环境来做时效性研究，渲染使用 Python 3 标准库。已有材料的复盘可明确限定到给定材料与日期。
